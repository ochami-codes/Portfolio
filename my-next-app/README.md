# Portfolio

My personal portfolio website — where I bring together all my work in one place.

**Live:** `https://ian-s-portfolio.vercel.app`
**Stack:** Next.js, TypeScript, Tailwind CSS

---

### Overview

A fast, minimal, and responsive portfolio built to showcase my journey from scattered HTML files to full-stack platforms. It houses my projects, skills, and contact.

Built with the same stack as SAM-Frontend — Next.js + TypeScript + Tailwind — so it's performant and SEO-friendly.

### Features

- **About Me** - Who I am and what I do
- **Projects** - SAM, CMS, CBE, Advent-project with live links & GitHub
- **Skills** - Tech stack visualization
- **Experience / Timeline** - My growth story
- **Contact** - Direct email / socials
- **Responsive** - Works on mobile, tablet, desktop
- **SEO Ready** - Next.js metadata, fast load

### Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide / React Icons
- **Deployment:** Vercel
